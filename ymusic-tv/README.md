# Яндекс Музыка TV

Неофициальное приложение для Android TV: веб-версия music.yandex.ru во весь экран, без интерфейса браузера,
с управлением пультом. Официального приложения Яндекс Музыки для Android TV нет. Для личного использования.
Сделано на основе Jut.su TV / 2SUB TV.

## Своё меню

При запуске открывается собственный экран приложения (обычные Android-элементы, быстрый на ТВ):

- большие плитки: **Моя волна**, **Мне нравится**, **Коллекция**, **Поиск**, **Чарт**, **Тренды**,
  **Подкасты и книги**, **Настройки**;
- панель **«Сейчас играет»**: обложка, название, исполнитель и кнопки ⏮ ⏯ ⏭; фон экрана мягко окрашивается
  в цвет обложки.

Плитка открывает раздел, нажимая пункт меню самого сайта с таким названием (адреса страниц у Яндекса
меняются, названия — редко); если пункт не нашёлся, открывается адрес раздела. Сайт загружается и играет
за меню; пока меню на экране, страница не отрисовывается — ТВ рисует только меню.

## Пульт

| Где | Кнопка | Что делает |
|---|---|---|
| Меню | стрелки, OK | выбрать плитку / кнопку плеера и нажать |
| Меню | Назад ×2 | свернуть приложение (музыка продолжит играть) |
| Меню | Меню | вернуться в открытый раздел сайта |
| Раздел | стрелки, OK | рамка по трекам и плейлистам, включить |
| Раздел | Назад | закрыть окно сайта, иначе вернуться в меню |
| Раздел | Меню | вернуться в меню |
| Везде | ⏯ ⏭ ⏮ ⏪ ⏩ | плеер (если такие кнопки есть на пульте) |

## Сборка и установка (Windows, PowerShell, в этой папке)

```powershell
powershell -ExecutionPolicy Bypass -File build-and-install.ps1
```

## Скорость на слабом ТВ

- Скрипт пульта не реагирует на постоянные мелкие изменения страницы (полоса прогресса, таймеры) — только
  на появление новых элементов и окон.
- Отключены размытие под панелями, длинные и бесконечные анимации сайта, большая анимированная
  визуализация «Моей волны».
