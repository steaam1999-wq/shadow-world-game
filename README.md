# ТЕНИ: ПОСЛЕДНИЙ ВОИН

Браузерная dark fantasy RPG: пошаговые бои, лут, прокачка, боссы, Башня Теней, арена и коллекция теней.

**Цикл игры:** бой → награда → прокачка → новый бой → лучший лут → арена → босс.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + production-сборка в dist/
npm run preview  # запуск собранной версии
npm run sim      # симуляция баланса (автопрохождение кампании всеми классами)
```

Стек: React 19, TypeScript, Vite, Tailwind CSS 4, Lucide React. Бэкенда нет — прогресс хранится в `localStorage`.

## Что есть в игре

| Система | Содержание |
| --- | --- |
| Классы | Берсерк, Страж, Ассасин, Маг Тени, Монах клинков — у каждого свои модификаторы и 3 способности (открываются на 1, 5 и 12 уровне) |
| Бой | Пошаговый: атака, защита, сильный удар, способности, зелья. Криты, уклонение, блок, кровотечение, яд, горение, оглушение, баффы и дебаффы, всплывающие цифры урона, лог боя, автобой и ускорение ×2 |
| Враги | 29 обычных врагов и 7 боссов с уникальными механиками (регенерация, кража атаки + ярость, ядовитая аура, отражающий щит, казнь, перерождение, нарастающая сила) |
| Локации | 6 локаций по 5 боёв, последний бой — босс. Следующая локация открывается после победы над боссом |
| Экипировка | 7 слотов, 6 редкостей, случайные характеристики, улучшение до +15, сравнение с надетым предметом |
| Инвентарь | Сетка, фильтры (оружие/броня/аксессуары/редкость), сортировка (сила/редкость/уровень), продажа, массовая продажа, блокировка |
| Прокачка | XP и уровни (до 60), 3 очка характеристик за уровень (Сила, Ловкость, Выносливость, Тьма), сброс характеристик |
| Арена | Симуляция PvP против сгенерированных соперников, рейтинг (старт 1000, +25/−15), таблица лидеров, недельные сезоны с наградами, магазин за жетоны |
| Башня | 100 этажей, босс каждые 10 этажей, награды за этаж, рекорд сохраняется |
| Тени | 18 теней с бонусами и пассивными способностями, уровни I–V, слияние двух одинаковых теней, призыв за осколки, 3 слота |
| Экономика | Золото, кристаллы, осколки теней, жетоны арены; лавка (зелья, сундуки), отдых в лагере |
| Задания | 5 ежедневных заданий из пула с наградами и сбросом каждый день + сундук дня |
| Достижения | 19 достижений с уведомлениями и наградами |
| Звук | Синтезированные эффекты и эмбиент-музыка через Web Audio API (без внешних файлов) |
| Сохранение | Автосохранение в `localStorage`, ручное сохранение и сброс прогресса с подтверждением в настройках |

## Структура

```
src/
  types/        общие типы
  data/         классы, враги, локации, предметы, тени, задания, достижения
  game/         чистая игровая логика (без React)
    combat.ts       боевой движок: раунд → список шагов со снимками состояния
    stats.ts        расчёт характеристик героя и ботов арены
    hero.ts         опыт, уровни, очки характеристик
    items.ts        генерация лута, сила предмета, улучшение
    inventory.ts    экипировка, продажа, улучшение
    rewards.ts      итоги боя и начисление наград
    arena.ts        соперники, рейтинг, сезоны, лидеры
    tower.ts        этажи башни
    shadows.ts      получение, слияние, призыв теней
    quests.ts       ежедневные задания и достижения
    shop.ts         лавка и отдых
    save.ts         SaveAdapter + localStorage
  hooks/        GameProvider (состояние, автосохранение, уведомления), запуск боёв
  components/   UI-компоненты (панели, предметы, награды, оверлеи)
  pages/        экраны игры
  utils/        случайность, форматирование, звук
```

### Расширение

- **Новый класс:** добавьте id в `ClassId` (`src/types`), описание в `src/data/classes.ts` и обработчики способностей в `useClassAbility` (`src/game/combat.ts`).
- **Бэкенд:** реализуйте интерфейс `SaveAdapter` (`src/game/save.ts`) и передайте его в `<GameProvider adapter={...}>`. Вся игровая логика в `src/game` — чистые функции над `GameState`, поэтому её можно перенести на сервер.
