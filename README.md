# Искра

Дейтинг-сервис, где вместо анкет — конкретные планы на ближайшие 48 часов, а на договорённость даётся 72 часа.

Сейчас в репозитории фронтенд-прототип (`web/`): React + TypeScript + Vite + Tailwind CSS. Данные демонстрационные и хранятся в `localStorage` браузера, бэкенда пока нет.

## Что есть

- **Лендинг**: слоган, анимированные карточки встреч, «как это работает», безопасность, истории.
- **Вход и онбординг**: Telegram / Google / телефон (заглушки), вайб-тест из 6 экранов, профиль.
- **Идеи**: лента активностей и схема города, фильтры по радиусу, времени и категориям, создание своей активности.
- **Вайб**: подборка по совместимости, отклик сразу на план, жалобы.
- **Капсулы**: чаты с таймером 72 часа, статусы «Договорились о встрече», «Обменялись контактами», «Встреча состоялась».
- **Профиль**: вайб-тест, интересы, уровни и значки, верификация селфи, приватность.
- **Админ-панель** (`#admin`): модерация верификаций и жалоб, аналитика, категории, теги и системные уведомления.

## Запуск

```bash
cd web
npm install
npm run dev          # http://localhost:5173
npm run build        # сборка в web/dist
npm run build:single # весь сайт одним файлом в web/dist-single/index.html
```
