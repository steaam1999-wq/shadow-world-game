# ARCANE SURVIVORS

> «Когда погаснут последние звёзды, останется лишь тот, кто осмелится зажечь их снова».

Мрачная фэнтезийная история о последнем маге ордена Арканистов и survivor-like в одной игре.
Игра работает в браузере: просто открой `index.html` (собранный бандл уже лежит в `dist/`).

## Графика (2.5D, WebGL)

- Изометрическая камера сверху под углом, как в современных Action RPG.
- Three.js: тени, туман, динамические точечные источники света от заклинаний и жаровен, bloom-свечение.
- Герой, 12 видов врагов и 4 босса собраны из десятков деталей и анимированы: ходьба, атака, полёт, щупальца, крылья, плащи.
- Сотни врагов рендерятся инстансингом: одна отрисовка на деталь модели.
- Частицы и эффекты считаются на GPU: шлейфы снарядов, цепные молнии, огненные кольца, ударные волны, магические круги с рунами, дым, искры, гибель врагов.
- Своя земля и декорации у каждой главы: каменные плиты и колонны с жаровнями, бирюзовый лес со светящимися грибами, склеп с надгробиями и свечами, расколотая земля Бездны с кристаллами.
- Фэнтезийный HUD: медальон-портрет с кольцом Сердца Эфира, кованые полосы, ячейки заклинаний с процедурными иконками, всплывающие цифры урона.
- Качество подстраивается само: если FPS падает, отключаются тени врагов, потом все тени, затем снижается разрешение.

## Два слоя игры

**Бой.** Динамичный survivor-like: сотни врагов, автоматические заклинания, элитные «носители памяти»,
приливы Бездны и страж в конце каждой главы (на 4:00).

**Сюжет.** Между боями ты возвращаешься в Убежище: там диалоги, хроники с найденными фрагментами
памяти, постоянные улучшения и решения, которые влияют на финал.
**Смерть — не поражение:** каждый забег открывает новый фрагмент истории.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Движение | WASD / стрелки | виртуальный джойстик (касание экрана) |
| Сердце Эфира | Пробел / E | кнопка ✦ |
| Пауза | Esc / P | кнопка ❚❚ |
| Выбор улучшения | 1–3, R — перебор | касание карточки |

## Что есть в игре

- **4 главы:** Падшее королевство, Лес Шёпота, Город мёртвых и Сердце Бездны. У каждой своя палитра, свой ландшафт и свои враги.
- **4 босса со своими механиками:**
  - Падший рыцарь: рывки с предупреждением, веер клинков.
  - Древний пожиратель: притягивает героя, призывает волков.
  - Король без души: кольца снарядов, телепорт, призыв магов.
  - Владыка Бездны: три фазы, спирали, зоны тьмы.
- **6 заклинаний**, у каждого есть эволюция (5 уровень + нужный артефакт):
  - Чародейская стрела → Звёздный град (Гримуар).
  - Цепная молния → Вечный шторм (Сапоги странника).
  - Огненное кольцо → Пламя Феникса (Руна простора).
  - Ледяные осколки → Абсолютный ноль (Кристалл времени).
  - Кровавые серпы → Багровая жатва (Сердце феникса).
  - Сфера Бездны → Чёрная дыра (Око Бездны).
- **5 магических школ** на выбор с 6-го уровня: Маг Бездны, Повелитель молний, Хранитель огня, Кровавый маг, Ледяной архонт.
- **Сердце Эфира.** Заряжается от поглощённой энергии и даёт мощный взрыв по всему экрану. Но каждое использование повышает **Порчу**.
- **Порча.** Постоянная шкала «насколько Бездна видит тебя». Она меняет ауру героя, оттенок мира и одну из концовок.
- **16 фрагментов памяти:** раскрывают тайну наставника Элиана, его дочери Лиры и истинную природу магии.
- **Концовки:**
  - Печать: Бездна запечатана, магия уходит из мира.
  - Поглощение: финал «Хранитель» или «Новый Владыка», в зависимости от Порчи.
  - Тайная концовка «Рассвет»: открывается, только если собраны все фрагменты.
- **Наследие:** постоянные улучшения за Эфир (здоровье, урон, скорость, радиус сбора, перебор, очищение Порчи).

- **Поведение врагов:**
  - Волки и гули с предупреждением делают рывок.
  - Рыцари, древни, големы и ужасы бьют по земле: сначала появляется рунный круг.
  - Порождения Бездны раздуваются и взрываются рядом с героем.
  - Стрелки держат дистанцию.
- **Сценарные волны:** натиск с одной стороны (на экране — стрелка направления), засада стрелков, разлом Бездны, стая чемпионов, приливы.
- **Вторые фазы боссов:**
  - «Клятва нарушена»: рыцарь оставляет огненный след.
  - «Голод без дна»: корни вокруг героя.
  - «Корона в огне»: дождь проклятий.
  - У Владыки Бездны три фазы.
- **Живой мир:** разрушаемые урны, коконы и кристаллы (эфир, лечение, магнит, временная «Сила Эфира»), светящиеся руны на земле, стелющийся туман.
- **Стратегия улучшений:** на карточках шкала уровня и путь к эволюции, внизу текущая сборка, а среди вариантов всегда есть прокачка уже взятого заклинания.
- **Прочее:** критические удары, мини-карта.

- **Звук и музыка** синтезируются в браузере через Web Audio, без файлов:
  - мрачный эмбиент со своей тональностью у каждой главы;
  - барабаны, которые нарастают вместе с толпой врагов и ускоряются при появлении босса;
  - около 25 эффектов: заклинания, попадания, сбор эфира с нарастающей высотой, рёв босса, предупреждения об атаках.
  - Музыку и звуки можно отдельно выключить в паузе, общий переключатель есть в Убежище.

Прогресс хранится в `localStorage` браузера.

## Структура

```
index.html        — разметка экранов
css/style.css     — оформление меню
js/data.js        — сюжет, главы, враги, боссы, заклинания, концовки (весь контент — здесь)
js/save.js        — сохранение прогресса
js/icons.js       — процедурные иконки заклинаний и артефактов
js/ui.js          — Убежище, диалоги, выбор улучшений, финал
src/logic.js      — игровая логика: спавн, ИИ боссов, заклинания, урон
src/render.js     — 2.5D-рендер: камера, свет, bloom, враги, эффекты
src/models.js     — модели героя, врагов и боссов с анимацией
src/world.js      — окружение глав: земля, освещение, декорации
src/fx.js         — GPU-частицы и декали
src/textures.js   — процедурные текстуры
src/hud.js        — фэнтезийный HUD
dist/arcane.js    — собранный бандл (его подключает index.html)
```

Сюжетный контент правится в `js/data.js` без пересборки. После изменений в `src/` пересобери бандл:

```
npm install
npm run build
```
