# Shadow World Simulator

Симулятор для Roblox: игрок ловит тени, получает **эссенцию тьмы**, прокачивает фонарь, открывает новые зоны и перерождается ради постоянного множителя.

## Что уже есть

| Система | Где в коде |
|---|---|
| Генерация мира: 5 зон, мосты, ночная атмосфера | `src/server/WorldService.luau` |
| Тени с полоской здоровья, ловля кликом, авто-ловля | `src/server/WorldService.luau` |
| Сохранение прогресса (DataStore, автосейв, сохранение при выключении) | `src/server/DataService.luau` |
| Улучшения, открытие зон, перерождение, ежедневная награда | `src/server/GameService.luau` |
| Game Passes и Developer Products с защитой от двойной выдачи | `src/server/MonetizationService.luau` |
| Интерфейс: счётчик, меню, магазин, уведомления | `src/client/` |
| **Весь баланс и цены** | `src/shared/Config.luau` |

Вся логика работает на сервере. Клиент только показывает данные и отправляет запросы, поэтому читер не сможет выдать себе эссенцию.

## Самый простой запуск (без Rojo)

1. Установите [Roblox Studio](https://create.roblox.com/) (только Windows или Mac).
2. Скачайте файл [`build/ShadowWorld.rbxlx`](build/ShadowWorld.rbxlx) и откройте его в Studio.
3. Нажмите **Play** (или F5).

После изменений в `src/` пересоберите файл: `python3 tools/build_place.py`.

## Запуск через Rojo (для разработки)

1. Установите [Roblox Studio](https://create.roblox.com/) и [Rokit](https://github.com/rojo-rbx/rokit).
2. В папке проекта выполните:
   ```bash
   rokit install   # установит Rojo нужной версии
   rojo serve
   ```
3. В Studio установите плагин **Rojo**, создайте новое место (шаблон *Baseplate*) и нажмите **Connect** в плагине.
4. Нажмите **Play**: мир построится сам.

Для сохранения в Studio включите **Game Settings → Security → Enable Studio Access to API Services**. Без этого игра работает, но прогресс не сохраняется (в Output будет предупреждение).

Другой вариант без Rojo: выполните `rojo build -o ShadowWorld.rbxl` и откройте этот файл в Studio.

## Как включить монетизацию

1. Опубликуйте игру: **File → Publish to Roblox**.
2. На [create.roblox.com](https://create.roblox.com/) откройте игру и перейдите в **Monetization**:
   - **Passes** — создайте 3 пропуска: *x2 Эссенция*, *Авто-ловля*, *Теневой VIP*;
   - **Developer Products** — создайте 4 продукта: *Буст x2*, *Горсть*, *Сосуд* и *Сундук эссенции*.
3. Скопируйте их ID в `src/shared/Config.luau` (поля `id = 0`).
4. Пока ID равен `0`, кнопка в магазине показывает «Не настроено».

Цену в Robux задаёте в Creator Dashboard, игра подтянет её сама.

## Вывод денег (DevEx)

Заработанные Robux можно обменять на реальные деньги через [Developer Exchange](https://create.roblox.com/docs/production/earning-on-roblox#developer-exchange). Нужны возраст 13+, подтверждённая личность и минимальная сумма Robux. Актуальные условия смотрите по ссылке.

## Что делать дальше

- **Своя карта**: заменить сгенерированные платформы красивой картой из Toolbox или собственной.
- **Звуки и эффекты** при ловле теней.
- **Таблица лидеров** по всем серверам (OrderedDataStore).
- **Квесты и бейджи** для удержания игроков.
- **Иконка, превью и описание игры**: они сильно влияют на клики в рекомендациях.
