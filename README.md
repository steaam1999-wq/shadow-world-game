# Искра

Дейтинг-сервис, где вместо анкет — конкретные планы на ближайшие 48 часов, а на договорённость даётся 72 часа.

Сейчас в репозитории фронтенд-прототип (`web/`): React + TypeScript + Vite + Tailwind CSS. Данные демонстрационные и хранятся в `localStorage` браузера, бэкенда пока нет.

## Что есть

Интерфейс приложения сделан в стиле Инстаграма, а механика своя: планы на 48 часов и капсулы на 72 часа.

- **Лендинг**: слоган, анимированные карточки встреч, «как это работает», безопасность, истории.
- **Вход и онбординг**: Telegram / Google / телефон (заглушки), вайб-тест из 6 экранов, профиль.
- **Главная**: сторис с планами людей (автопролистывание, ответ сразу открывает капсулу) и лента постов: лайк двойным тапом, закладки, отклик на план полосой под фото.
- **Поиск**: поиск по планам, плиточная сетка, подборка «Люди» по совместимости, карта районов, фильтры.
- **Новый план** (+): фото или обложка категории, время, район и точное место (видно только в капсуле).
- **Сообщения**: капсулы с таймером 72 часа и статусами «Договорились о встрече», «Обменялись контактами», «Встреча состоялась».
- **Уведомления** (сердечко): ответы в капсулах, лайки ваших планов, объявления.
- **Профиль**: фото, счётчики, значки как «Актуальное», сетка своих планов и сохранённого, настройки вайб-теста и приватности, верификация.
- **Админ-панель** (`#admin`): модерация верификаций и жалоб, аналитика, категории, теги и системные уведомления.

## Запуск

```bash
cd web
npm install
npm run dev          # http://localhost:5173
npm run build        # сборка в web/dist
npm run build:single # весь сайт одним файлом в web/dist-single/index.html
```
