# ARCANE SURVIVORS

> «Когда погаснут последние звёзды, останется лишь тот, кто осмелится зажечь их снова».

Мрачная фэнтезийная история о последнем маге ордена Арканистов и survivor-like в одной игре.
Игра работает в браузере без сборки и зависимостей: просто открой `index.html`.

## Два слоя игры

**Бой.** Динамичный survivor-like: сотни врагов, автоматические заклинания, элитные «носители памяти»,
приливы Бездны и страж в конце каждой главы (на 4:00).

**Сюжет.** Между боями ты возвращаешься в Убежище: там диалоги, хроники с найденными фрагментами
памяти, постоянные улучшения и решения, которые влияют на финал.
**Смерть — не поражение:** каждый забег открывает новый фрагмент истории.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Движение | WASD / стрелки | виртуальный джойстик (касание экрана) |
| Сердце Эфира | Пробел / E | кнопка ✦ |
| Пауза | Esc / P | кнопка ❚❚ |
| Выбор улучшения | 1–3, R — перебор | касание карточки |

## Что есть в игре

- **4 главы:** Падшее королевство, Лес Шёпота, Город мёртвых и Сердце Бездны. У каждой своя палитра, свой ландшафт и свои враги.
- **4 босса со своими механиками:**
  - Падший рыцарь: рывки с предупреждением, веер клинков.
  - Древний пожиратель: притягивает героя, призывает волков.
  - Король без души: кольца снарядов, телепорт, призыв магов.
  - Владыка Бездны: три фазы, спирали, зоны тьмы.
- **6 заклинаний**, у каждого есть эволюция (5 уровень + нужный артефакт):
  - Чародейская стрела → Звёздный град (Гримуар).
  - Цепная молния → Вечный шторм (Сапоги странника).
  - Огненное кольцо → Пламя Феникса (Руна простора).
  - Ледяные осколки → Абсолютный ноль (Кристалл времени).
  - Кровавые серпы → Багровая жатва (Сердце феникса).
  - Сфера Бездны → Чёрная дыра (Око Бездны).
- **5 магических школ** на выбор с 6-го уровня: Маг Бездны, Повелитель молний, Хранитель огня, Кровавый маг, Ледяной архонт.
- **Сердце Эфира.** Заряжается от поглощённой энергии и даёт мощный взрыв по всему экрану. Но каждое использование повышает **Порчу**.
- **Порча.** Постоянная шкала «насколько Бездна видит тебя». Она меняет ауру героя, оттенок мира и одну из концовок.
- **16 фрагментов памяти:** раскрывают тайну наставника Элиана, его дочери Лиры и истинную природу магии.
- **Концовки:**
  - Печать: Бездна запечатана, магия уходит из мира.
  - Поглощение: финал «Хранитель» или «Новый Владыка», в зависимости от Порчи.
  - Тайная концовка «Рассвет»: открывается, только если собраны все фрагменты.
- **Наследие:** постоянные улучшения за Эфир (здоровье, урон, скорость, радиус сбора, перебор, очищение Порчи).

Прогресс хранится в `localStorage` браузера.

## Структура

```
index.html      — разметка экранов
css/style.css   — оформление
js/data.js      — сюжет, главы, враги, боссы, заклинания, концовки (весь контент — здесь)
js/save.js      — сохранение прогресса
js/game.js      — боевой движок: спавн, ИИ боссов, заклинания, отрисовка на Canvas
js/ui.js        — Убежище, диалоги, выбор улучшений, финал
```

Чтобы добавить врага, заклинание или реплику, достаточно отредактировать `js/data.js`.
