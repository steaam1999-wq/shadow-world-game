# shadow-world-game

## Shadow Casino 🌑

Виртуальное казино в браузере. Играем только на виртуальные фишки — никаких реальных денег.

### Запуск

Просто откройте `index.html` в браузере (сборка и сервер не нужны).

### Игры

Интерфейс: лобби с плитками игр и категориями, баннер-карусель, боковое меню, нижняя навигация на телефоне, страница истории со статистикой.

| Игра | Правила |
|------|---------|
| 🚀 Ракета | Краш-игра: раунды идут непрерывно, заберите ставку до того, как ракета улетит. Автовывод, ставка на следующий раунд. P(множитель ≥ m) = 0.97 / m |
| 💣 Мины | Поле 5×5, 1–24 мины. Каждая открытая клетка повышает множитель, забрать можно в любой момент |
| 🔻 Плинко | 12 рядов, три уровня риска (до ×10 / ×33 / ×170), можно бросать несколько шаров сразу |
| 🎰 Слоты | 3 барабана, взвешенные символы, ~94% отдачи. Три одинаковых или две вишни |
| 🎡 Рулетка | Европейская (одно зеро). Число 35:1, дюжины 2:1, цвет / чёт-нечет / половины 1:1. ПКМ по полю — снять ставку |
| 🃏 Блэкджек | 6 колод, дилер стоит на 17, блэкджек 3:2, удвоение на первых двух картах |
| 🎲 Кости | Число 0–99, угадайте, что выпадет меньше цели. Множитель = 99 / шанс |

### Фишки

- Старт: 1000 фишек.
- Бонус +200 раз в час; если фишек меньше 10 — бонус +1000 доступен сразу.
- Баланс и история сохраняются в `localStorage`; кнопка ⟲ сбрасывает прогресс.
- Случайность — через `crypto.getRandomValues`.
