# Искра

Дейтинг-сервис, где вместо анкет — конкретные планы на ближайшие 48 часов, а на договорённость даётся 72 часа.

Фронтенд (`web/`): React + TypeScript + Vite + Tailwind CSS. Сервер — Supabase: аккаунты по почте, общие профили, планы, капсулы и чат с живыми обновлениями (схема и правила доступа — `web/supabase/schema.sql`). Без ключей Supabase приложение работает как локальное демо с данными в `localStorage`. Сайт: https://steaam1999-wq.github.io/shadow-world-game/

## Что есть

Интерфейс приложения сделан в стиле Инстаграма, а механика своя: планы на 48 часов и капсулы на 72 часа.

- **Главная**: простая страница входа и регистрации по центру и пример аккаунта «Женя», который открывается без регистрации. Вход без сервера: «Войти» возвращает последний профиль в этом браузере.
- **Онбординг**: после регистрации — вайб-тест из 6 экранов и профиль.
- **Встречи по-настоящему**: «Свободен сейчас» в ленте (кто рядом свободен в ближайшие часы, «Позвать» открывает капсулу); «Отметить встречу» кодами из 4 цифр и надёжность «приходит N%» в профилях; «Я на встрече» — таймер безопасности с сообщением доверенному контакту.
- **Компании и вторая встреча**: групповые планы на 3–4 человека («Присоединиться к компании», кто уже идёт, свободные места, фильтр «Компании 3–4»); после подтверждённой встречи — тайное «хочу ещё», при взаимности капсула открывается снова на 72 часа.
- **Главная**: сторис с планами людей (автопролистывание, ответ сразу открывает капсулу) и лента постов: лайк двойным тапом, закладки, отклик на план полосой под фото.
- **Планы на весь экран** (как Reels): вертикальная лента по одному плану на экран, лайк двойным тапом, кнопки справа.
- **Мои песни** (раздел «Музыка»): загрузка своих аудиофайлов кнопкой или перетаскиванием, несколько сразу; хранятся в IndexedDB браузера, переживают перезагрузку; переименование, удаление, песня в профиле.
- **Музыка** (нота в шапке): свои песни, поиск и тренды в интернете (Audius — целиком, iTunes — отрывки по 30 секунд, радио Radio Browser), песни людей рядом, любимые; ссылки на Яндекс Музыку и Spotify открываются в их встроенных плеерах.
- **Музыкальный плеер** в стиле Яндекс Музыки: большая обложка, лайк и «не нравится», очередь «Далее», текст песни с подсветкой строк (LRCLIB), скачивание разрешённых треков.
- **Самолётик под постом**: нажатие — меню «Поделиться» (друзья, поделиться, копировать); долгое нажатие — справа выезжают 5 человек, с кем вы чаще переписываетесь, и к выбранному улетает самолётик, а план приходит в капсулу.
- **Чужой профиль**: нажатие на имя или аватар в посте, сторис, подборке, ряду «Люди в Искре» или чате; подписка, «Написать» (личная переписка без плана), сетка планов.
- **Поиск**: поиск по планам, плиточная сетка, подборка «Люди» по совместимости, карта районов, фильтры.
- **Новый план** (+): фото или обложка категории, время, район и точное место (видно только в капсуле).
- **Сообщения**: капсулы с таймером 72 часа и статусами «Договорились о встрече», «Обменялись контактами», «Встреча состоялась».
- **Уведомления** (сердечко): ответы в капсулах, лайки ваших планов, объявления.
- **Профиль**: фото, счётчики, значки как «Актуальное», сетка своих планов и сохранённого, настройки вайб-теста и приватности, верификация.
- **Админ-панель** (`#admin`): модерация верификаций и жалоб, аналитика, категории, теги и системные уведомления.

## Запуск

```bash
cd web
npm install
npm run dev          # http://localhost:5173
npm run build        # сборка в web/dist
npm run build:single # весь сайт одним файлом в web/dist-single/index.html
```

## Visual Studio Code

1. Скачайте проект: на GitHub ветка `claude/iskra-site` → **Code → Download ZIP** (или `git clone`), распакуйте.
2. В VS Code: **File → Open Folder…** → папка проекта. VS Code предложит расширения — нажмите **Install**.
3. **Запустить Искру:** откройте `python/iskra.py` и нажмите ▶ (Run Python File) — или клавишу **F5** («Искра (Python, одним файлом)»). Откроется браузер с приложением. Нужен только Python 3.8+.
4. **Менять код:** нужен Node.js 20+. **Terminal → Run Task…** → «Искра: установить зависимости», затем «Искра: запустить для разработки» — сайт на http://localhost:5173 обновляется при сохранении файлов. «Искра: собрать в один файл» делает `web/dist-single/index.html`.
