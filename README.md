# CS2 Case Bot

Телеграм-бот — симулятор открытия кейсов CS2 со скинами. Работает на внутриигровых монетах 🪙:
их нельзя купить или вывести, это не азартная игра на деньги.

## Возможности

- 🎁 **Кейсы** — «Революция», «Грёзы и кошмары», «Разлом» с реальными шансами CS2 по редкостям
  (🟦 79.92% · 🟪 15.98% · 🩷 3.2% · 🟥 0.64% · 🟨 0.26%), анимация прокрутки
- 🎲 Износ (FN/MW/FT/WW/BS) с float, StatTrak™ (10%) — оба влияют на цену
- 🎒 **Инвентарь** с пагинацией, продажа по одному или всего сразу
- 💰 **Бонус** раз в 24 часа, 👤 **профиль** (лучший дроп, статистика), 🏆 **топ** игроков

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости и задайте токен:

   ```bash
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env   # впишите BOT_TOKEN
   ```

3. Запустите:

   ```bash
   python -m csbot
   ```

## Настройка

| Переменная             | По умолчанию     | Описание                       |
|------------------------|------------------|--------------------------------|
| `BOT_TOKEN`            | —                | токен бота (обязателен)        |
| `DB_PATH`              | `csbot.sqlite3`  | файл базы SQLite               |
| `START_BALANCE`        | `1000`           | стартовый баланс               |
| `DAILY_BONUS`          | `250`            | размер бонуса                  |
| `BONUS_COOLDOWN_HOURS` | `24`             | период бонуса                  |

Кейсы, скины и цены редактируются в `csbot/catalog.py`. Цена кейса подобрана так, что средняя
стоимость дропа ≈ 85% от неё (проверяется тестом).

## Структура

```
csbot/
  catalog.py    кейсы, скины, редкости, износ
  game.py       логика выпадения и мат. ожидание
  db.py         SQLite (пользователи, предметы)
  keyboards.py  клавиатуры и callback-данные
  handlers.py   обработчики команд и кнопок
  __main__.py   точка входа
```
