# Shadow Drop — кейсы и апгрейды CS2

Симулятор сайта с кейсами CS2: открытие кейсов с рулеткой, апгрейды, контракты, батлы и Provably Fair.
Сайт статический (HTML + CSS + JS, без сборки и зависимостей), работает прямо из файла или на GitHub Pages.

> Это демо. Монеты и предметы виртуальные: реальных платежей, покупки и вывода скинов нет.

## Запуск

Откройте `index.html` в браузере. Или поднимите локальный сервер:

```bash
python3 -m http.server 8000   # затем http://localhost:8000
```

Для публикации достаточно включить GitHub Pages для ветки (Settings → Pages → Deploy from a branch, папка `/`).

## Что взяли у лучших сайтов

Разобрали механики популярных CS2-площадок (Hellcase, Key-Drop, CSFail, GGDrop, Farmskins, CSGORun, DaddySkins и т.п.)
и собрали самое удачное:

| Механика | Где подсмотрели | Как сделано у нас |
|---|---|---|
| Горизонтальная рулетка кейса с плавной остановкой и «дожимом» | почти все сайты | Лента из 56 предметов, остановка в случайной точке выигрышной ячейки, режим «Быстро» |
| Открытие x1–x5 за раз | Key-Drop, GGDrop | Несколько лент параллельно, общий экран дропа |
| Шансы каждого предмета на странице кейса | Hellcase, Key-Drop | Проценты у каждой карточки, отсортировано по цене |
| Апгрейд с колесом шансов и множителями x1.5…x20 | CSFail, GGDrop | Ставка до 6 предметов + монеты, шанс = ставка / цель × 0.95 (макс. 80%), стрелка крутится до честного числа |
| Контракты (10 → 1) | CSFail, Farmskins | 3–10 предметов, результат x0.25–x4 от суммы, виден диапазон |
| Батлы кейсов | Key-Drop, Hellcase | 2–4 игрока, 1–5 раундов, вертикальные ленты, победитель забирает всё |
| Живая лента дропов | все сайты | Лента под шапкой, клик ведёт на кейс |
| Бесплатный ежедневный кейс, промокоды, уровни | Hellcase, Farmskins | Кейс раз в 24 ч с таймером, промокоды `SHADOW`, `CS2`, `UPGRADE`, уровень растёт от потраченного |
| Provably Fair | CSGORun, CSFail | HMAC-SHA256(serverSeed, clientSeed:nonce:cursor), хеш сида виден заранее, раскрытие и проверка на странице |
| Моментальная продажа дропа | все сайты | Кнопка «Продать» сразу после выпадения и массовая продажа в инвентаре |

Чего **не** стали копировать: скрытые шансы, «подкрученные» ленты, где выигрышная ячейка не совпадает с результатом,
и агрессивные поп-апы с депозитом.

## Честность и математика

- **Кейсы.** Вес предмета `w = цена^(-α)`; `α` для каждого кейса подбирается бинарным поиском, чтобы средний дроп
  (с учётом износа и StatTrak™) был равен `RTP × цена кейса` (RTP ≈ 88–90%). Так дорогие скины реже, а баланс автоматический —
  можно добавлять кейсы, не считая шансы руками.
- **Износ:** FN 10% (×1.6), MW 20% (×1.2), FT 40% (×1.0), WW 15% (×0.85), BS 15% (×0.75). **StatTrak™:** 10% (×1.8).
- **Апгрейд:** победа, если число `< шанс`. Зелёная дуга колеса — ровно этот интервал.
- **Контракт:** множитель `0.25 × 16^(r²)`, матожидание ≈ 0.92, шанс окупиться ≈ 29%.
- **Provably Fair:** `roll = первые 13 hex HMAC_SHA256(serverSeed, "clientSeed:nonce:cursor") / 2^52`.
  cursor 0 — предмет, 1 — износ, 2 — StatTrak™. В демо сиды живут в браузере; на боевом сайте серверный сид должен храниться на сервере.

## Структура

```
index.html            разметка, шапка, лента
css/style.css         тема и адаптив
js/sha256.js          SHA-256 / HMAC без зависимостей
js/data.js            скины, кейсы, баланс шансов, каталог
js/store.js           состояние игрока (localStorage) и Provably Fair
js/ui.js              иконки скинов (SVG), карточки, модалки, тосты
js/reel.js            рулетка (горизонтальная и вертикальная)
js/pages/*.js         страницы: кейсы, апгрейд, контракты, батлы, инвентарь, честная игра
js/app.js             роутер, живая лента, демо-пополнение, промокоды
```

Иконки оружия — стилизованные SVG-силуэты в цветах скина (без чужих картинок и логотипов).
