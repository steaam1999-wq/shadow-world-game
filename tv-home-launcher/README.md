# Домашний экран — лаунчер для Android TV

Приложение-лаунчер для телевизора iFFALCON/TCL (Android TV 11): главный экран из `../tv-home-web/index.html`
(живой фон, жидкое стекло, вкладки, настройки), который открывается при включении ТВ и по кнопке «Домой».

Внутри лаунчера страница получает мост `window.Android`, поэтому:

- плитки запускают **установленные приложения** (Кинопоиск, YouTube, Okko, Wink, …); если приложения нет,
  открывается сайт в Яндекс Браузере;
- в настройках (шестерёнка) есть раздел **«Настройки телевизора»**: сеть, аккаунты, приложения, пульты и
  Bluetooth, входы HDMI, дата и время, язык, клавиатура, хранилище, заставка, об устройстве,
  местоположение, спец. возможности, для разработчиков, все настройки;
- кнопки сверху «Источники» (HDMI) и Wi‑Fi открывают системные экраны;
- в «Изменить → Добавить» можно выбрать любое приложение, установленное на ТВ;
- «Назад» на пульте закрывает окна и возвращает к первой плитке, «Домой» — на главный экран.

Экран один: правки делаются в `tv-home-web/index.html`, сборка копирует его в приложение сама.

## Установка (PowerShell на ноутбуке, в этой папке)

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -TvHost 192.168.0.102
```

Скрипт собирает APK (JDK 17 + Android SDK 34), ставит его по Wi‑Fi ADB, запоминает текущий лаунчер в
`previous-home.txt` и делает «Домашний экран» главным.

Вернуть прежний лаунчер (CleanYourTV):

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -TvHost 192.168.0.102 -Restore
```

Отладка страницы на ТВ: Chrome на ноутбуке → `chrome://inspect` → «Домашний экран».
