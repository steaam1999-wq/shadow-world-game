# Домашний экран — лаунчер для Android TV

Нативный лаунчер для телевизора iFFALCON/TCL (Android TV 11, armv7, 1,5 ГБ): только системные View,
поэтому все движения рисует аппаратный рендерер, как в меню самого ТВ.

- Крупные плитки 16:9 с **настоящими баннерами приложений** (те, что приложения дают для главного экрана
  Android TV); если баннера нет — иконка приложения на карточке его цвета. Сайт-ярлык Jut.su — с иконкой сайта.
- Выбранная плитка увеличивается с пружиной, белая рамка, фон плавно перекрашивается в цвет приложения.
- Вкладки «Главная», «Кино и сериалы», «Видео», «Музыка», «Все приложения» (стеклянная панель).
- Удерживайте OK (или кнопку меню) на плитке: добавить на «Главную» / убрать / сдвинуть / о приложении.
- Фон — картинка выбранного приложения, сильно размытая (считается один раз на крошечной копии баннера).
- Сверху круглые кнопки-иконки: входы HDMI и Wi‑Fi. Кнопка меню или настроек на пульте открывает список
  всех экранов настроек ТВ и яркость главного экрана.
- «Назад» и «Домой» возвращают на «Главную» к первой плитке.

Веб-версия экрана для браузера осталась в `../tv-home-web/`.

## Установка (PowerShell на ноутбуке, в этой папке)

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -TvHost 192.168.0.102
```

Скрипт собирает APK (JDK 17 + Android SDK 34), ставит его по Wi‑Fi ADB, запоминает текущий лаунчер в
`previous-home.txt` и делает «Домашний экран» главным.

Вернуть прежний лаунчер (CleanYourTV):

```powershell
powershell -ExecutionPolicy Bypass -File install.ps1 -TvHost 192.168.0.102 -Restore
```

Отладка страницы на ТВ: Chrome на ноутбуке → `chrome://inspect` → «Домашний экран».
