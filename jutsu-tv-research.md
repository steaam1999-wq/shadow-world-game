# Приложение Jut.su для Android TV: исследование и план

Дата: 2026-11-03. ТВ: iFFALCON 55K610 (TCL, Android TV 11, SDK 30, armv7, ~1,5 ГБ RAM). На ТВ стоят наш
лаунчер «Домашний экран», Яндекс Браузер и VPN. Ноутбук Windows: JDK 17 + Android SDK 34, ADB по сети
(192.168.0.102:5555). Сборка Android-приложений на нём уже проверена (лаунчер, 2SUB TV).

Цель: смотреть Jut.su на ТВ как в полноценном приложении, а не в браузере: вход в свой аккаунт, навигация
пультом по каталогу, сериям и вкладкам, удобный плеер. В перспективе — чтобы приложение могли поставить и
другие люди.

## 1. Что известно о сайте

- **jut.su** — русскоязычный сайт с аниме (озвучка и субтитры, аккаунты, достижения, подписка «Jut.su Plus»).
  **4 декабря 2024 года Роскомнадзор ограничил к нему доступ** вместе с AnimeGO, Yummy Anime, Kara.su,
  Animedia. Официальная причина не названа (версии в прессе — закон о «пропаганде ЛГБТ» или откровенные
  сцены). Из России сайт открывается только через VPN.
- **jut-su.net**, который вы смотрите, упоминается в подборках как адрес Jut.su, но **официальным
  зеркалом он нигде не подтверждён**. Это может быть копия от других людей. Для приложения это важно:
  адрес сайта нужно делать настраиваемым, а не зашивать в код.
- **Адреса страниц** (по открытым парсерам jut.su): серия — `/<аниме>/season-1/episode-1.html`,
  у части тайтлов без сезона — `/<аниме>/episode-19.html`. Понятные постоянные адреса удобны для
  «продолжить просмотр», «следующая серия» и кнопки «Назад».
- **Вход в аккаунт есть.** По описанию одного из парсеров, прямые ссылки на видео (для скачивания)
  отдаются только с подпиской Plus. Для просмотра на сайте это не мешает, а вот «свой плеер» в обход
  сайта это усложняет (см. вариант B).
- **Не удалось проверить из облака** (домен закрыт в сетевых настройках сессии): какой плеер на
  jut-su.net (свой `<video>` или iframe чужого видеохостинга), как устроен вход (почта/пароль,
  VK, Google), есть ли Cloudflare/DDoS-Guard, сколько рекламы и всплывающих окон. Это 30 минут
  разведки с ноутбука — список в п. 7.

## 2. Варианты реализации

| Вариант | Суть | Плюсы | Минусы | Оценка |
|---|---|---|---|---|
| **A. Приложение-обёртка (WebView + TV-слой)** | Сайт внутри приложения без интерфейса браузера; поверх — управление пультом, крупный интерфейс, клавиши плеера | Работает **всё, что есть на сайте**: вход, история, закладки, достижения, озвучки. Быстро. **Основа уже есть** — наш 2SUB TV (`twosub-tv/`): WebView, навигация стрелками, плеер, кнопки пульта, всплывающие окна входа | Удобство зависит от вёрстки сайта; меняется сайт — иногда правим скрипт | **Рекомендую** |
| B. Нативное приложение (свой интерфейс + свой плеер ExoPlayer) | Каталог в стиле Netflix, данные вытаскиваются из HTML сайта парсером | Максимально «как Netflix», быстро на слабом ТВ | Официального API нет: парсер ломается при любой правке сайта. Ссылки на видео без Plus могут быть недоступны. Вход, история, достижения — переписывать. Работы в разы больше | Только как этап 2 и только для каталога |
| C. Гибрид | Нативные главная/поиск/каталог (B) + страница просмотра в WebView (A) | Красивый каталог + надёжный просмотр с аккаунтом | Сложнее A, всё равно парсер | Вариант для v2 |
| D. Готовые решения | Яндекс Браузер/TV Bro (браузеры), Media Station X (уже стоит на ТВ) | Ничего не писать | Это остаётся браузером; MSX требует отдельной адаптации сайта под себя | Не решает задачу |

Готовых приложений Jut.su для Android TV — ни официальных, ни открытых на GitHub — поиск не нашёл.

## 3. Рекомендуемая архитектура (вариант A, на базе 2SUB TV)

**Стек:** тот же, что у лаунчера и 2SUB TV: Java (или Kotlin), Gradle, AGP 8.5.2, compileSdk/targetSdk 34,
minSdk 24, без сторонних библиотек (опционально `androidx.webkit` для внедрения скрипта до загрузки страницы).
Ничего нового на ноутбук ставить не нужно.

**Лучше сразу сделать ядро общим**, а сайт — «профилем»:

```
webtv-core/        общий код из twosub-tv: WebView, пульт, полноэкранное видео, входы, ошибки сети
profiles/jutsu/    jutsu.js + jutsu.css: селекторы сайта, клавиши плеера, «следующая серия»
profiles/twosub/   то же для 2SUB
```

Тогда новые сайты добавляются одним файлом, а исправления ядра получают все приложения сразу.

**Что умеет приложение (MVP):**
- Полноэкранный WebView без адресной строки; иконка и баннер на главном экране ТВ (наш лаунчер сам
  возьмёт баннер приложения для плитки).
- **Вход в аккаунт** как на сайте; cookies сохраняются между запусками. Окна входа через VK/Telegram —
  через `onCreateWindow` (уже сделано в 2SUB TV). Вход через Google в WebView Google блокирует —
  только почта/пароль или другие способы.
- **Пульт по всему сайту:** стрелки двигают заметную рамку фокуса по ссылкам, карточкам, вкладкам,
  сериям; OK — открыть; «Назад» — закрыть окно / назад по истории / выход двойным нажатием.
- **Плеер:** OK — пауза; ← → — перемотка ±10 с (удержание — быстрее); ↑ ↓ — панель плеера (озвучка,
  качество, субтитры); ⏯ ⏪ ⏩ на пульте; кнопки «Пропустить опенинг» и **«Следующая серия»** по нажатию
  или автоматически.
- **Продолжить просмотр:** приложение запоминает последнюю открытую серию (по адресу страницы) и
  предлагает её при запуске.
- **Адрес сайта в настройках приложения** + запасные адреса: если домен сменится или его заблокируют,
  меняем адрес без новой сборки.
- **Защита:** переходы на чужие домены (реклама, «вы выиграли») не открываются внутри приложения;
  всплывающие окна — только для входа.
- Отладка с ноутбука через `chrome://inspect` (как в 2SUB TV): так настраиваются селекторы.

**Производительность на этом ТВ:** WebView Android 11 обновляется через «Android System WebView» в Google
Play — проверить версию. Тяжёлые анимации сайта отключаем CSS-инъекцией; страница рендерится в ширину
1280 CSS px (как в 2SUB TV), чтобы на 1080p всё было крупно и читаемо.

**VPN:** приложение пользуется сетью ТВ, отдельно ничего не нужно. Если VPN работает в режиме
«только выбранные приложения», новое приложение надо добавить в список.

## 4. Риски и что проверить заранее

1. **Плеер в iframe с другого домена** (частая схема у аниме-сайтов). Тогда фокус и клавиши внутри
   плеера требуют отдельной обработки: скрипт внедряется и во фреймы, либо управляем через `postMessage`/
   клавиши, либо открываем плеер отдельно. Решается, но это главный объём работы.
2. **Защита от ботов** (Cloudflare/DDoS-Guard): WebView обычно проходит проверку как браузер; если нет —
   ставим десктопный user-agent (уже так в 2SUB TV).
3. **Реклама и редиректы** у неофициальных копий сайтов бывают агрессивными — блокируем переходы на
   чужие домены и новые окна.
4. **Смена/блокировка домена** — настраиваемый адрес (п. 3).
5. **Вход через Google** в WebView невозможен — использовать почту/пароль.

## 5. Распространение для других людей

- **Google Play — нет.** Приложение для чужого сайта с его названием и логотипом без разрешения владельца
  Play отклоняет (политики об имитации и интеллектуальной собственности). К тому же контент сайта
  публикуется без подтверждённых лицензий, а Google TV отдельно борется с пиратскими приложениями.
- **Реально:** APK на GitHub Releases (или своём сайте) → установка на ТВ через приложение «Downloader»
  по короткому коду или через ADB, как мы ставили лаунчер.
- **Важное изменение 2026 года:** Google вводит **проверку разработчиков даже для приложений вне Play**
  на сертифицированных устройствах (к ним относятся Android TV / Google TV). Регистрация в Android
  Developer Console открыта, обязательной проверка становится по странам начиная с 30.09.2026.
  По заявлениям Google, продвинутые пользователи сохранят возможность ставить непроверенные приложения.
  Для публичной раздачи планировать регистрацию разработчика; для себя — установка через ADB.
- **Юридически:** приложение-обёртка само ничего не хранит и не раздаёт — оно показывает сайт. Но
  публично распространять клиент для сайта, который выкладывает аниме без подтверждённых прав и
  заблокирован в РФ, — уже риск для того, кто распространяет. Безопаснее всего:
  - для себя и знакомых — без ограничений;
  - для широкой публики — **общий «ТВ-клиент для сайтов»** без названия и логотипа Jut.su, где адрес сайта
    вводит пользователь, а профиль Jut.su — один из вариантов; либо с разрешения владельцев сайта.

## 6. Оценка сложности

| Этап | Что входит | Объём |
|---|---|---|
| Разведка | 30 мин с ноутбука по списку п. 7 | 1 короткая сессия |
| MVP (A) | Форк 2SUB TV → профиль Jut.su: вход, пульт по каталогу, плеер, «следующая серия», «продолжить», адрес в настройках, иконка/баннер | 1–2 сессии (если плеер не в iframe); +1 сессия, если в iframe |
| Удобство | Свой стартовый экран «Продолжить / Закладки / Новые серии» поверх сайта, крупные карточки | +1–2 сессии |
| Общее ядро | Вынести ядро в `webtv-core`, 2SUB и Jut.su как профили | +1 сессия |
| v2 (C) | Нативный каталог через парсер страниц | +1–2 недели, только если очень нужно |

**Итог: несложно.** Почти всё ядро уже написано и проверено на 2SUB TV; основная неизвестная — устройство
плеера на jut-su.net, её закрывает разведка.

## 7. Разведка с ноутбука перед стартом (~30 мин, Chrome, VPN включён)

Открыть jut-su.net → F12 → вкладки **Elements** и **Network**:

1. **Плеер:** открыть серию. Видео — это `<video>` на самой странице или `<iframe>`? Если iframe — с какого
   домена (скопировать адрес). Источник видео: `.m3u8`, `.mp4`, сегменты? Есть ли выбор озвучки/качества
   и где эти кнопки в HTML (классы/id).
2. **Навигация серий:** есть ли на странице серии кнопки «следующая/предыдущая» и «пропустить опенинг»
   (классы/id).
3. **Вход:** какие способы входа предлагает сайт; пускает ли по почте/паролю.
4. **Защита:** есть ли при первом заходе проверка «Checking your browser» (Cloudflare/DDoS-Guard).
5. **Реклама:** открываются ли новые вкладки/всплывающие окна при кликах.
6. **Адреса:** формат страниц аниме, сезона, серии, поиска (`/search/?...`), закладок/истории.
7. Сделать скриншоты главной, страницы аниме, страницы серии и плеера — по ним спроектирую навигацию.

Результаты можно прислать скриншотами — этого хватит, чтобы начать MVP.
