# Jut.su TV

Неофициальное приложение для Android TV: сайт Jut.su во весь экран, без интерфейса браузера, с управлением
пультом. Сайт делает всё сам (каталог, аккаунт, история, плеер); приложение добавляет ТВ-слой. Сделано на
основе 2SUB TV (`../twosub-tv`). Для личного использования; план и ограничения — `../jutsu-tv-research.md`.

## Пульт

| Где | Кнопка | Что делает |
|---|---|---|
| Страницы | ← ↑ → ↓ | рамка фокуса по ссылкам, карточкам, вкладкам, сериям |
| Страницы | OK | открыть / нажать |
| Страницы | Назад | закрыть окно, затем назад по страницам; дважды на первой — выход |
| Плеер | OK | пауза / воспроизведение |
| Плеер | ← → | −10 / +10 секунд |
| Плеер | ↓ | «Пропустить опенинг», когда кнопка видна; иначе меню плеера |
| Плеер | ↑ | меню плеера (озвучка, качество, серии) |
| Везде | ⏯ ⏪ ⏩ | пауза, −30 / +30 секунд |
| Везде | ⏭ ⏮ | следующая / предыдущая серия |
| Везде | Меню | «Продолжить» (последняя серия), «Главная», «Обновить», «Адрес сайта» |

- Рамка фокуса плавно переезжает между элементами; при удержании стрелки страница прокручивается без рывков.
- «Назад» возвращает к той же карточке или серии, с которой вы ушли.
- Страница серии открывается сразу на плеере; когда серия заканчивается, через 8 секунд включается
  следующая (любая кнопка — остаться).

Вход: почта/пароль, VK, Telegram, Яндекс работают внутри приложения; вход через Google внутри приложений
Google блокирует. Переходы на чужие сайты (реклама) не открываются. Сайт заблокирован в РФ — нужен VPN на ТВ
(если VPN работает только для выбранных приложений, добавьте Jut.su TV в список).

Адрес по умолчанию — `https://jut-su.net/`. Если сайт переедет: кнопка меню → «Адрес сайта».

## Сборка и установка (Windows, PowerShell, в этой папке)

```powershell
powershell -ExecutionPolicy Bypass -File build-and-install.ps1 -TvHost 192.168.0.102
```

Нужны JDK 17 и Android SDK 34 (как для лаунчера) и ADB по сети на ТВ.

## Настройка под сайт

`WebView.setWebContentsDebuggingEnabled(true)` включён: с ТВ, подключённым по ADB, откройте в Chrome на
ноутбуке `chrome://inspect` → «Jut.su TV» → inspect, чтобы видеть живую страницу. Так подстраиваются
селекторы в `assets/tv.js` (кнопки плеера, следующая серия).

## Что проверить на ТВ

- Плеер: если видео встроено с другого сайта (iframe), клавиши плеера могут потребовать доработки.
- Кнопки «Пропустить опенинг» и «Следующая серия» — по тексту на кнопках.
