# Приложение 2SUB для Android TV: исследование и план

Дата: 2026-11-02. ТВ: iFFALCON 55K610 (TCL BeyondTV4, Android TV 11, SDK 30, armv7, ~1.5 ГБ RAM),
на нём уже стоит лаунчер CleanYourTV; ноутбук Windows с JDK 17 + Android SDK 34 (сборка проверена).

## 1. Что за сервис

- **2SUB / 2sub.movie** — русскоязычный онлайн-кинотеатр: фильмы и сериалы в оригинальной озвучке
  с **двойными интерактивными субтитрами** для изучения языков (испанский, немецкий, французский,
  итальянский, английский): перевод слова по нажатию, озвучка, личный словарь, тренировки в Telegram-боте.
  Есть аккаунты и партнёрская программа, то есть это коммерческий сервис.
- **Официального приложения для Android TV не нашлось.** Поиск ничего не дал. Нужно ещё проверить
  на самом сайте (раздел «Приложения»/FAQ) и в Google Play на ТВ.
- Из облачной сессии сайт не открылся, потому что домен вне разрешённой сети. Структуру страниц,
  плеер и API нужно смотреть с ноутбука (см. п. 5).

## 2. Варианты реализации

| Вариант | Суть | Плюсы | Минусы | Оценка |
|---|---|---|---|---|
| **A. Своё приложение-«обёртка» на WebView + TV-слой** | Нативное Android TV приложение (Kotlin), сайт внутри WebView без интерфейса браузера; поверх добавляется навигация пультом, крупный масштаб, кнопки пульта → плеер | Работают **все функции сайта**, включая интерактивные субтитры и словарь; логин как на сайте; быстрая разработка | Удобство зависит от вёрстки сайта; надо подстраивать CSS/JS | **Рекомендую для старта** |
| B. Нативное приложение на API сайта | Свой интерфейс (Leanback / Compose for TV), данные через внутренний JSON API сайта, свой плеер (Media3/ExoPlayer) | Максимально «как Netflix», быстро на слабом ТВ | API неофициальный, может сломаться в любой момент; **интерактивные субтитры придётся писать заново**; объём работы в разы больше | Только как этап 2, если API удобный |
| C. Гибрид | Нативные экраны каталога/поиска (B) + страница просмотра в WebView (A) | Красивый каталог + все фишки плеера | Сложнее A | Вариант для v2 |
| D. Готовые решения | TV Bro (открытый TV-браузер на Kotlin, ~1.5k ★, есть смена user-agent), Media Station X | Ничего не писать | Это всё равно браузер, а не приложение; MSX требует адаптации со стороны сайта | Не решает задачу |

TWA / «PWA как приложение» на Android TV не подходит: на ТВ нет Chrome, на который она опирается.

## 3. Рекомендуемая архитектура (вариант A)

- **Язык/сборка:** Kotlin, Gradle, minSdk 21–24, targetSdk 34. Тот же стек, что уже собирается
  на ноутбуке для лаунчера CleanYourTV (JDK 17, SDK 34), то есть ничего доустанавливать не нужно.
- **Манифест:** `android.software.leanback` (required=false), `touchscreen` required=false,
  категория `LEANBACK_LAUNCHER`, баннер 320×180, чтобы приложение появлялось на главном экране ТВ.
- **Один экран: `Activity` + `WebView`**, без адресной строки.
  - `CookieManager` с `setAcceptThirdPartyCookies`: логин сохраняется между запусками.
  - JS, DOM storage, `mediaPlaybackRequiresUserGesture=false`, кэш.
  - Полноэкранное видео: `WebChromeClient.onShowCustomView/onHideCustomView`.
  - DRM (если есть Widevine): `onPermissionRequest` → `PROTECTED_MEDIA_ID`.
  - Ссылки на чужие домены не открывать (или открывать с предупреждением).
- **TV-слой (главное):**
  - Навигация стрелками: полифилл **WICG spatial-navigation** (`spatial-navigation-polyfill`,
    его поддерживают инженеры LG) или своя логика фокуса по карточкам. Скрипт внедряется до загрузки страницы
    через `androidx.webkit` `addDocumentStartJavaScript` (по возможности и в iframe).
  - CSS-инъекция: крупнее шрифты и карточки, заметная рамка фокуса, скрыть мелкие элементы,
    которые неудобны с пульта (подход «10-foot UI»).
  - Кнопки пульта: Back → назад по истории / выход из полноэкранного режима; Play/Pause, ⏪/⏩ →
    управление `<video>`; меню → переключение субтитров/языка.
  - Режим «курсора» как запасной вариант для мест, куда не дотягивается фокус.
  - Экранная клавиатура ТВ для логина и поиска работает в WebView штатно.
- **Производительность на этом ТВ:** WebView на Android 11 обновляется через Play («Android System
  WebView»), проверить версию. ТВ слабый (armv7), так что тяжёлые анимации сайта отключить через CSS.

## 4. Риски и что проверить заранее

1. **Как устроен плеер.** Свой `<video>` + HLS (hls.js) — идеально. Если видео в **iframe с чужого
   домена** (частая схема), фокус и кнопки пульта внутри iframe потребуют отдельной обработки.
2. **Вход в аккаунт.** Логин/пароль или по почте работает. **Вход через Google внутри WebView
   Google блокирует** (`disallowed_useragent`). Вход через Telegram/VK — проверить. Запасной путь:
   «войти по коду с телефона», если сайт так умеет, или войти по паролю.
3. **Интерактивные субтитры.** На сайте они рассчитаны на мышь/наведение. С пульта нужен режим
   «выбор слова стрелками → OK = перевод». Это, скорее всего, основная доработка.
4. **Защита сайта от встраивания** (проверка user-agent, Cloudflare-челленджи) — проверить с ТВ.
5. **VPN.** На ТВ уже стоит VPN; приложение просто пользуется сетью ТВ, ничего особого не нужно.

## 5. Что сделать с ноутбука перед стартом (разведка ~30 мин)

- Открыть 2sub.movie в Chrome → F12 → вкладка **Network**:
  - посмотреть, откуда грузится видео (`.m3u8`/`.mpd`, домен, iframe ли это);
  - есть ли JSON-запросы каталога (`/api/...`), чтобы понять, возможен ли вариант B/C.
- Проверить способы входа на сайте (почта/пароль, Google, Telegram).
- Посмотреть, есть ли у сайта раздел «Приложения»/«Smart TV».
- Сделать скрины главной, страницы фильма и плеера, чтобы спроектировать навигацию.

## 5a. Результаты разведки (2026-11-02, Chrome на ноутбуке)

- **Вход:** Google, Яндекс, почта, Telegram, VK (`login-modal.js`). В WebView: почта ✅, Яндекс ✅ (проверить),
  Telegram/VK через всплывающее окно (нужны `setSupportMultipleWindows` + `onCreateWindow`), Google ❌.
- **Адреса:** понятные, серверные: `/film/<slug>/`, просмотр — тот же адрес с `#watch`
  (`/film/buddy-2026/#watch`). Удобно для «назад», «продолжить» и прямых ссылок.
- **Плеер — собственный, на той же странице, без iframe.** Видео идёт сегментами через XHR
  (`cde_<id>_...`, по 1–2 МБ), то есть потоковое воспроизведение через MSE (HLS/DASH в JS). WebView это поддерживает.
  Запросов к DRM-лицензиям не видно.
- **Интерфейс плеера:** панель «Диалоги» слева (список реплик EN+RU с таймкодами, поиск, настройки),
  двойные субтитры поверх видео (EN белым, RU жёлтым), переключатели EN/РУ, ← / → (вероятно,
  предыдущая/следующая реплика), «Пропустить заставку», настройки, полный экран.
- **Трейлеры** — встроенный YouTube (iframe). Второстепенно, управление пультом внутри него ограничено.
- **Реклама/аналитика:** Яндекс.Метрика, Sentry, преролл `yandex.ru/ads/vmap` (VAST). В приложении
  можно оставить как есть.
- **Сайт — PWA** (в Chrome есть «Установить»): есть manifest с названием и иконками, их можно
  взять для баннера и иконки приложения.

**Вывод:** самый удобный случай для варианта A. Никаких iframe в основном плеере, нет DRM, понятные адреса.
Схема управления пультом в плеере:
OK = пауза/плей, ← / → = предыдущая/следующая реплика (кнопки сайта) или перемотка ±10 с,
↑ = открыть/фокус на панель «Диалоги» (переход по репликам, OK = перейти к реплике),
↓ = переключение EN/РУ субтитров, Back = закрыть плеер. Слово в субтитрах: режим выбора
слова стрелками → OK = перевод (вызвать тот же обработчик, что срабатывает по клику мышью).

## 6. Распространение для других людей

- **Свободно и сразу:** APK через GitHub Releases / свой сайт; установка на ТВ через приложение
  «Downloader» (по короткому коду) или через ADB, как мы ставили лаунчер.
- **Google Play:** нужно соответствие требованиям TV-приложений (баннер, работа без тача, D-pad).
  Приложение, которое оборачивает **чужой сайт и бренд** без разрешения владельца, Google Play
  отклоняет (политика об имитации и интеллектуальной собственности).
- **Правильный путь для публичного релиза:** договориться с 2SUB (у них есть партнёрская программа,
  а своего ТВ-приложения, судя по поиску, нет). Либо они дают разрешение или делают приложение
  официальным, либо распространять как неофициальный клиент без их логотипа. Для личного
  использования ограничений нет. Сам контент и права на него — зона ответственности сайта; приложение
  его не хранит и не раздаёт.

## 7. Оценка сложности

| Этап | Что входит | Объём |
|---|---|---|
| MVP (вариант A) | WebView-приложение, логин, навигация пультом, полноэкранный плеер, кнопки пульта, иконка на главном экране | 1–2 рабочих сессии |
| Удобство | Крупный TV-интерфейс через CSS, режим выбора слов в субтитрах, «продолжить просмотр» | +2–4 сессии (зависит от вёрстки сайта) |
| v2 (вариант C) | Нативный каталог/поиск в стиле Netflix через API сайта | +1–2 недели, только если API удобный |

Итог: **несложно**. Начинать с WebView-приложения с TV-слоем: оно сохраняет все функции сайта и
быстро собирается тем же инструментарием, что уже стоит на ноутбуке.
